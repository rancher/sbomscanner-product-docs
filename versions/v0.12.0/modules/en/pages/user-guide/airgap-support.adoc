= Air Gap Support
:revdate: 2026-10-09
:page-revdate: {revdate}
:description: Run {sboms-name} in air-gapped environments with mirrored dependencies.

{sboms-name} can be used in air-gapped environments.

To run the scans, {sboms-name} currently needs the following external sources:

* Vulnerability Database
* Java Vulnerability Database
* VEX Hub (optional)

These external sources can be self-hosted in your private infrastructure to make the whole environment air-gapped.

== Self-Hosting Vulnerability Databases

The Vulnerability Databases are packaged as OCI images, allowing you to host them in your own registry. By default, {sboms-name} pulls them from the SUSE registry:

* `registry.rancher.com/suse-security/vulnerability-scanner/trivy-db:2`
* `registry.rancher.com/suse-security/vulnerability-scanner/trivy-java-db:1`

Once mirrored in your own OCI registry, you can install {sboms-name} to point to them:

[source,shell]
----
helm install sbomscanner \
    oci://dp.apps.rancher.io/charts/suse-security-vulnerability-scanner \
    --version 0.12.1 \
    --namespace sbomscanner \
    --set 'global.imagePullSecrets={application-collection}' \
    --set worker.trivyDBRepository="yourlocalregistry.example/suse-security/vulnerability-scanner/trivy-db:2" \
    --set worker.trivyJavaDBRepository="yourlocalregistry.example/suse-security/vulnerability-scanner/trivy-java-db:1"
----

== Self-Hosting VEX Hub

To setup your own VEX Hub repository, please refer to this https://github.com/aquasecurity/trivy/blob/main/docs/docs/advanced/self-hosting.md#make-a-local-copy-1[guide].

Change the `repository_url` (if any) within the VEX files, to point to the internal registries.

All you need to do is to setup an HTTP server to provide the needed files for VEX.

By default, {sboms-name} seeds two `VEXHub` resources pointing to the public `github.com/rancher/vexhub` and `github.com/aquasecurity/vexhub` repositories, which are unreachable in an air-gapped environment. Disable this seeding at install time by setting `controller.defaultVEXHubResources` to `false`:

[source,shell]
----
helm install sbomscanner \
    oci://dp.apps.rancher.io/charts/suse-security-vulnerability-scanner \
    --version 0.12.1 \
    --namespace sbomscanner \
    --set 'global.imagePullSecrets={application-collection}' \
    --set controller.defaultVEXHubResources=false
----

To configure a VEX Hub in {sboms-name}, create a `VEXHub` resource with your local repository URL and apply it:

[source,yaml]
----
apiVersion: sbomscanner.kubewarden.io/v1alpha1
kind: VEXHub
metadata:
  name: local_vexhub
spec:
  url: "https://yourlocalrepo.example/"
  enabled: true
----
